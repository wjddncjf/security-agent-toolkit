# 서버에서 파일 속 글 고치기 - vim

## 찾아본 것
서버에서 설정 파일을 고치는 방법: 서버에 VS Code가 없을 때, 보안 담당자는 SSH를 통해 서버에 연결한 후 명령줄 텍스트 편집기(보통 vi/vim)를 사용하여 구성 파일을 직접 편집합니다. 어떤 컴퓨터든 최소한 vi라는 글쓰기 도구를 꼭 넣어야한다는 POSIX 표준이 있기 때문에 보안 담장자는 vim을 사용한다.

## 오늘 새로 쓴 명령
vim

## vim 으로 한 것
입력 모드로 들어가는 키: i
일반 모드로 돌아오는 키: Esc
저장하고 나가는 명령: :wq
저장 없이 나가는 명령: :!q
지운 것을 되돌리는 키: u

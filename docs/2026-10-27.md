## Network-004 F2: 조건에 맞는 값의 개수와 합계

### 직접 변경한 값
- 기존: counts = [0, 4, 2, 5]
- 변경: counts = [7, 4, 2, 5]

### 실제 실행 결과
- 출력: 3 16

### 결과가 나온 이유
- 3 이상인 숫자는 7, 4, 5로 총 3개이다.
- 조건에 맞는 숫자의 합계는 7 + 4 + 5 = 16이다.
- 2는 3 미만이므로 개수와 합계에서 제외된다.

### 새롭게 알게 된 점
- for 반복문으로 리스트의 값을 하나씩 확인할 수 있다.
- if 조건문으로 특정 조건에 맞는 값만 선택할 수 있다.

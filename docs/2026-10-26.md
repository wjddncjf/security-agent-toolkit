## 오늘 새로 쓴 명령
- pwd : 지금 위치한 폴더의 경로를 출력
- ls : 해당 폴더 안의 목록 출력
- ls -a : 이름이 점으로 시작하는 항목까지 출력

## 찾아보고 알게 된 것
- 보안 담당자가 리눅스를 쓰는 이유: 서버 인프라의 대부분이 리눅스이고, 보안 도구 자체가 CLI 기반이다., 명령어는 기록으로 남고 스크립트로 공유 및 재현이 가능해 감사 추적과 팀 협업에 유리하다.

- GitHub : Git버전 관리 시스템을 기반으로 구축된 클라우드 호스팅 서비스

- GitHub 사용 이유: 개발자의 핵심 요구는 효율적인 협업과, 버전 관리 및 기술 역량 전시이다. 따라서 GitHub는 전 세계 개발자 공통 언어이기 때문에 표준화된 협업 및 버전 관리가 가능하고, 개발자가 참여하여 기술을 향상 시킬 수 있을 뿐만 아니라, "기술 이력서"의 역할도 가능하다.

보안 담당자는 GitHub의 기능을 활용하여 누가 언제 어떤 코드를 수정했는지 추적할 수 있다. 또한 악성 코드가 포함될 수 있는 타사 라이브러리를 식별한다.

개발자는 GitHub를 사용하여 "더 잘 작성"하고, 보안 담당자는 "더 안전하게 작성"한다.

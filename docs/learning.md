# 실행과 변경 기록

- 처음 적은 x의 값과 출력 : x = 3, 5
- 고친 x의 값과 출력 : x = 8, 10
- 저장, 커밋, 푸시의 차이 :
* 저장 : 편집한 내용을 내 PC의 파일에 반영
* 커밋 : 선택한 변경을 내 PC의 Git 이력에 기록
* 푸시 : 내 PC의 커밋을 GitHub 저장소로 전송
- 막혔던 곳과 확인한 방법 : 
* 막혔던 곳 : 다른 실습 파일도 변경 목록에 있어 무엇을 커밋해야 할지 헷갈렸다.
* 확인한 방법 : git add agent_core/main.py로 필요한 파일만 선택한 뒤 git diff --cached로 커밋할 내용을 확인했다.

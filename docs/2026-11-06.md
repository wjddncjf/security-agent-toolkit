# 파일 만들고 옮기고 지우기 — touch · cp · mv · rm

## 찾아본 것
서버에서 로그를 옮기고 백업하는 방법: 보안 담당자는 SSH 원격 연결을 통해 명령줄로 로그 파일을 전송하고 백업할 수 있다.
cp는 원본파일을 보존하면서 복사본을 생성하는 명령어이고, 로그 백업, 원본 로그 유지 필요 시 사용한다
mv는 원본 위치가 사라지거나 이름이 변경되고, 이름은 변경 또는 이동하는 명령어이다. 로그 아카이빙 후 원본 파일 삭제 또는 이름 변경 시 사용한다.

## 오늘 새로 쓴 명령
touch, cp, mv, rm, Tab 자동 완성

- touch 파일 : 빈 파일을 만든다. 같은 이름이 있으면 내용은 그대로 두고 수정 시각만 바꾼다.
- cp : copy의 약자로, 파일이나 디렉터리를 복사한다.
- mv : move의 약자로, 파일이나 디렉터리를 이동하거나 이름을 변경한다.
- rm : remove의 약자로, 파일이나 디렉터리를 삭제한다.

## 찾은 옵션
폴더째 복사 - cp-r  / 덮어쓰기 전에 묻기 - cp-i / 폴더째 지우기 - rm-r

## mv 의 두 가지 쓰임
이름 바꾸기: 대상이 존재하지 않는 이름일 때 원본이 그 이름으로 바뀐다.
- mv a.log b.log
옮기기: 대상이 존재하는 디렉터리일 때 원본이 그 디렉터리 안으로 들어간다.
- mv a.log backup    # a.log를 backup 안으로 이동

## 막힌 것
cp, mv, rm에 붙는 -r, -i 같은 옵션이 각각 무슨 기능인지 몰라서, 어떤 상황에 어떤 옵션을 써야 하는지 판단이 안 됐다. 그래서 옵션 하나하나를 물어보며 익혔다.

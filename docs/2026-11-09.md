# 2026-11-09 CSV,JSON으로 직은 보고서 만들기

## 1. 학습 내용

- `csv.reader()`와 `csv.DictReader()`의 차이 학습
- `reader()`는 데이터를 리스트로 읽어 인덱스로 접근
- `DictReader()`는 헤더를 키로 사용하여 칸 이름으로 접근
- JSON 파일을 읽고 전체 기록 수와 실패 건수를 집계하는 방법 학습
- `open()`의 `w` 모드를 사용하여 결과를 텍스트 파일에 저장하는 방법 학습

## 2. 코드 작성 및 변경·확인 사항

**F1 · CSV 실패 건수 집계**
- `gichan_input.csv`를 `DictReader`로 읽고 `row['result'] == 'FAIL'` 조건으로 실패 기록을 집계
- 예상 출력: `2`
- `FAIL` 조건을 `PASS`로 변경하면 집계 대상이 달라지는 점 확인 

**F2 · JSON 결과 보고서**
- JSON 데이터를 `json.load()`로 읽고 `len()`과 반복문으로 전체·실패 건수를 계산하는 코드 학습
- `summary.txt`에 결과를 저장하는 방법 확인
- 과제의 예상 결과: `전체 3건, 실패 2건`
- JSON 데이터를 빈 목록 `[]`으로 변경했을 때 `전체 0건, 실패 0건`이 출력되는지 확인 

## 3. 막히거나 헷갈렸던 부분

- csv.reader()는 인덱스로 값을 가져오고, csv.DictReader()는 헤더 이름으로 값을 가져온다는 차이를 이해하는 데 어려움이 있었다.
- JSON 파일을 읽어 전체 건수와 실패 건수를 각각 계산하고, 그 결과를 summary.txt에 저장하는 과정을 이해하는 데 시간이 필요했다.


## 4. 새롭게 알게 된 점

- open()의 w 모드를 사용하면 집계 결과를 summary.txt에 저장하고 기존 내용을 덮어쓸 수 있다.
- csv.DictReader()는 첫 번째 줄을 헤더로 사용하기 때문에 열 순서와 관계없이 row['result']처럼 원하는 값을 가져올 수 있다.

- 입력 파일이 없거나 `result` 키가 없는 경우의 오류 처리 방법 학습

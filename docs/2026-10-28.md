### 3. 새롭게 알게 된 점
- 가상환경(.venv)을 사용하면 프로젝트별로 Python 패키지를 관리할 수 있다.
- pip는 Python 패키지를 설치하고 관리하는 도구이다.
- requests는 HTTP 요청을 보내는 데 사용하는 Python 라이브러리이다.
- import requests로 라이브러리를 불러오고 __version__으로 버전을 확인할 수 있다.

## 2. 확인한 내용

### 2.1 함수의 기준값 변경

`needs_review()` 함수에서 `threshold=2`를 기본값으로 설정하고, 함수 호출 시 다른 기준값을 전달해 비교했다.

```python
print(needs_review(3))
print(needs_review(3, 5))
```
함수 내부의 조건문을 매번 수정하지 않아도 호출할 때 전달하는 값만으로 판단 기준을 변경할 수 있다는 점을 확인했다.

### 2.2 실패 횟수를 판단하는 함수의 기준 변경

`find_suspects()` 함수에서는 `Counter`로 사용자별 실패 횟수를 계산하도록 작성했다.
동일한 사용자 목록을 사용하면서 판단 기준을 기본값 2와 직접 전달한 값 5로 나누어 비교했다.

```python
find_suspects(['kim01', 'kim01', 'lee02', 'kim01'])

find_suspects(['kim01', 'kim01', 'lee02', 'kim01'], 5)
```

기준값이 달라지면 조건을 만족하는 사용자 목록도 달라진다. 여러 사용자의 실패 횟수를 직접 변수로 관리하는 대신 `Counter`를 사용하고, 반복문으로 조건에 맞는 사용자만 새로운 리스트에 추가하도록 작성했다.

### 2.3 입력 리스트를 변경해 함수 확인

`filter_three_or_more()` 함수에서는 리스트의 값 중 3 이상인 값만 반환하도록 작성했다.
일반적인 숫자 리스트와 빈 리스트를 각각 전달하는 코드를 작성했다.

```python
filter_three_or_more([1, 2, 4, 5])
filter_three_or_more([])
```

입력 데이터가 있는 경우뿐 아니라 데이터가 없는 경우까지 고려해 함수를 작성했다.
조건을 만족하는 값을 새로운 리스트에 추가하는 방식이므로, 조건을 만족하는 값이 없으면 빈 리스트가 반환되는 구조라는 점을 확인했다.

### 2.4 함수 반환값을 파일에 저장

`assignment_10_f2.py`에서는 `summarize()` 함수가 합계 문자열을 반환하도록 작성했다.
반환값을 `result` 변수에 저장한 후 `write()`를 이용해 `report.txt`에 기록했다.

```python
result = summarize([2, 3])

with open('report.txt', 'w') as f:
    f.write(result)
```

함수 내부에서 바로 파일을 작성하는 대신, 계산한 결과를 반환하고 함수 밖에서 파일에 저장하도록 처리했다. 
실제 `report.txt`에 `합계 5`가 저장된 것을 확인했다.

## 3. 막힌 내용 및 어려웠던 부분

- result = summarize([2, 3])을 작성할 때 숫자를 대괄호 []로 묶지 않아 오류가 발생했다. 함수가 숫자 두 개가 아닌 하나의 리스트를 전달받도록 작성되어 있다는 점을 확인하고, [2, 3]으로 수정했다.

- 매개변수에 =값을 지정하면 기본값이 된다는 개념이 이해하기 어려웠다. threshold=2를 설정한 후 인자를 생략한 경우와 5를 직접 전달한 경우를 비교하면서, 값을 전달하지 않으면 기본값을 사용하고 전달하면 해당 값으로 대체된다는 것을 이해했다.


## 4. 새롭게 알게 된 점

- 함수의 기본 매개변수를 활용하면 함수 내부 코드를 수정하지 않고도 판단 기준을 변경할 수 있다는 것을 알게 되었다.
- `Counter`를 활용하면 리스트에서 각 값이 등장하는 횟수를 간단하게 계산할 수 있다는 것을 알게 되었다.
- 조건문과 반복문을 함수로 묶으면 입력값만 변경해 같은 기능을 반복 사용할 수 있다는 것을 알게 되었다.
- 함수의 반환값은 화면에 출력하는 것뿐 아니라 변수에 저장하거나 파일에 기록하는 등 다른 작업에도 활용할 수 있다는 것을 알게 되었다.

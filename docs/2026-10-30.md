# 2026-10-30 학습 기록

## 1. 오늘의 학습 주제

Python 파일 입출력과 예외 처리

## 2. 학습 내용

- `open()`과 `with`를 이용한 파일 열기 및 자동 닫기
- `w` 모드로 파일 생성 및 내용 쓰기
- `r` 모드로 파일 내용 읽기
- `a` 모드로 기존 파일에 내용 추가
- `for line in f`를 이용한 한 줄씩 읽기
- `strip()`을 이용한 줄바꿈 및 양쪽 공백 제거
- `in` 연산자를 이용한 특정 문자열 검색
- `try-except`를 이용한 FileNotFoundError 처리

생성하고 읽고 수정하는 방법을 학습했다.

특히 CSV 형식의 로그를 한 줄씩 읽으면서

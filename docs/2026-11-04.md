wireshark란 네트워크에서 오가는 패킷을 수집하고 분석하여 어떤 데이터가 오고 가는지 확인할 수 있는 프로그램이다. 보안 담당자는 네트워크 상에서 발생하는 비정상적인 통신이나 해킹시도를 패킷을 열어 의심스러운 IP 주소, 통신 내용, 공격 흔적 등을 확인하여 찾아낼 수 있다.

패킷에는 실제 전송할 데이터뿐만 아니라 출발지와 목적지 IP 주소, 통신에 필요한 정보 등이 포함된다.

- Npcap (Network Packet Capture) : Windows에서 네트워크를 통해 오가는 패킷을 수집할 수 있도록 도와주는 프로그램이다.

* Npcap: 네트워크에서 패킷을 수집하는 역할
* Wireshark: 수집한 패킷을 화면에 보여주고 분석하는 역할

## Python 입력과 결과가 있는 함수

### 1. 오늘 학습한 내용

Python에서 함수를 정의하고, 입력값을 전달받아 처리한 결과를 반환하는 방법을 학습했다.

- **'def'**: 'def 함수이름(매개변수):' 형태로 함수를 정의한다.
- **매개변수(Parameter)**: 함수를 호출할 때 전달한 값을 함수 내부에서 사용할 수 있도록 한다.
- **'return'**: 함수에서 처리한 결과를 호출한 곳으로 돌려준다.
- **함수 호출**: 정의한 함수에 값을 전달하여 실행한다.
- **'print()'와 'return'의 차이**: 'print()'는 결과를 화면에 출력하고, 'return'은 결과를 반환하여 다른 곳에서도 활용할 수 있도록 한다.

### 2. 필수 F1 · 함수를 두 번 호출

이름을 전달받아 인사 문자열을 반환하는 'greet()' 함수를 만들고, 서로 다른 이름으로 두 번 호출한다.

**작성한 코드**

'''python
def greet(name):
    return '안녕하세요 ' + name

print(greet('기찬'))
print(greet('정민'))
'''

**실행 결과**

'''text
안녕하세요 기찬
안녕하세요 정민
'''

**학습 및 확인 내용**

- 'name'이라는 매개변수를 사용해 이름을 전달받도록 함수를 작성했다.
- 함수 내부에서 'print()'를 사용하지 않고 'return'으로 인사 문자열을 반환하도록 했다.
- 같은 함수를 두 번 호출하되 서로 다른 이름을 전달하도록 구성했다.
- 함수를 한 번 정의하면 입력값만 변경하여 재사용할 수 있다는 것을 학습했다.
-  'name' 입력값을 '우철', '길동'으로 변경 후 호출했을 떄
'''text
안녕하세요 우철
안녕하세요 길동
'''
으로 반환 되는 것을 확인했다.

### 3. 필수 F2 · 판단을 함수로 묶기

**과제 내용**

실패 횟수를 전달받아 조건에 따라 판단 결과를 반환하는 함수를 만든다. 입력값 2와 3을 사용해 판단 기준의 경계를 확인한다.

**작성한 코드**

'''python
def check_failures(count):
    if count >= 3:
        return '추가 확인'
    else:
        return '기록 유지'

print(check_failures(2))
print(check_failures(3))
'''

**실행 결과**

'''text
기록 유지
추가 확인
'''

**학습 및 확인 내용**

- 실패 횟수를 'count' 매개변수로 전달받도록 함수를 작성했다.
- 'if' 조건문을 사용해 실패 횟수가 3 이상인지 판단하도록 했다.
- 입력값이 2일 때는 '기록 유지', 3일 때는 '추가 확인'을 반환하도록 구성했다.
- 경계값인 2와 3을 비교하면서 조건에 따라 서로 다른 결과를 반환하는 방법을 학습했다.
- 기존 조건인 count >= 3을 count > 3 으로 변경하여 실행보았다. 입력 값이 3일때 '추가 확인'이 반환 되었지만, 조건 변경 후 '기록 유지'가 반환되는 차이를 확인했다.

### 4. 새롭게 알게 된 점

- 'def'를 사용하면 반복되는 작업을 하나의 함수로 정의하고 재사용할 수 있다.
- 매개변수를 활용하면 같은 함수라도 전달하는 값에 따라 서로 다른 결과를 얻을 수 있다.
- 'return'을 사용하면 함수에서 처리한 결과를 돌려받을 수 있다.
- 조건문을 함수 내부에 작성하면 입력값에 따른 판단 과정을 하나의 기능으로 묶을 수 있다.
